🛒 E-commerce Sales Analytics Project
📘 Overview

This project analyzes E-commerce sales data (2022–2025) from an Indian marketplace using MySQL and Power BI.
It focuses on identifying revenue patterns, customer behavior, and top-performing product categories to support data-driven decisions.



⚙️ Tech Stack

Database: MySQL

Visualization: Power BI

Language: SQL

Tools: Excel (for data cleaning), Power BI Desktop


🗃️ Dataset

Total records: 5,00+

Tables: customers, products, and sales

Currency: INR

Time period: 2022–2025


🧩 SQL Analysis Highlights

Total revenue by year and month

Top 5 customers and products by revenue

Category-wise and region-wise performance

Average order value and repeat purchase rate

Most used payment methods


📊 Power BI Dashboard Features

The E-commerce Sales Dashboard delivers interactive insights with a clean, professional layout.

🎯 KPI Cards

Total Customer Count — total unique customers

Average Price — average product price per transaction

Total Revenue — total revenue generated

🥧 Pie Chart

Most Used Payment Methods — distribution of payment types (UPI, Credit Card, Cash, etc.)

📊 Bar Chart

Top Performing Product Categories — top categories by total revenue

📦 Column Chart

Category-wise Quantity Sold — total units sold per product category

📈 Line Chart

Month-wise Revenue Trend — revenue growth visualization over time

🎛️ Slicers

Year-wise Filter — to filter results by year (2022–2025)

Category-wise Filter — to view sales performance per product category

🧾 How to Use

Import .csv files into MySQL using the provided scripts.

Run SQL analysis queries.

Connect Power BI to MySQL or CSV files.

Load visuals and interact using slicers for year and category.
